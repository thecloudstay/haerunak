# 해루낚

**물때 해석은 앱이 한다. 사용자는 어디 가서 뭘 잡을지 결론만 본다.**

### https://haerunak.com

전국 **259개 정밀 포인트**(도서 165곳)와 바다타임 색인 1,571곳을 대상으로
조석·수중시야·조류·솔루나·수온·기압·풍향(맞바람)·금어기를 종합해
오늘의 해루질·낚시 매력도를 0~100점으로 낸다.

## 구성

두 가지 판이 있고 서로 보완한다.

| | 정적 사이트판 (루트 `index.html`) | 앱스 스크립트판 (`gas/`) |
|---|---|---|
| 형태 | HTML 한 파일 (엔진·지도·해안선 내장) | `.gs` 10개 + 화면 3개 |
| 물때 | 자체 조석 계산 (±10~40분) | 바다타임 실측 + 자체 계산 폴백 |
| 기상 | 방문자 브라우저가 Open-Meteo 직접 조회 | 서버가 일괄 조회·캐시 |
| 조황 기록 | 그 기기에만 저장 | 구글 시트 공동 저장 + 점수 실측 보정 |
| 운영 | 없음 (정적) | 자가 운영 루프 (예열·재보정·소스 점검·감사) |
| 레퍼럴 | — | `?ref=` 코드 집계 |

정적 사이트판은 외부 의존이 거의 없다. 기본 지도는 앱 안에 내장한 해안선을 쓰므로
타일 공급사가 바뀌거나 유료화해도 영향받지 않는다. 세밀한 지도가 필요할 때만
위성·지도 타일을 부른다.

## 엔진 (두 판이 같은 코드를 쓴다)

- 선형파 분산관계 → 해저 궤도속도 → 재부유 → 광 감쇠 → **수중 시야(m)**
- 연안 정상파 조류 유속 (협수로 지형계수, 울돌목 14)
- 달 적경·적위(Meeus 축약) → 월출·월몰·남중 → 솔루나 활성기, 월광 조도
- 어종·채집물 70여 종 수온 적정 사다리꼴 + 월별 제철 달력
- 해안 방위각 × 풍향 → 맞바람/옆바람/등바람 체감 풍속
- 젖은 체감온도 — 비와 바람에 의한 증발 냉각까지
- 해역×바닥질 서식 어종 (모래→광어·보리멸, 펄→망둥어·숭어, 암반→감성돔·볼락)
- 섬 배편 — 간조 시각과 여객선 운항대가 어긋나는지 판정
- 금어기·금지체장 56규정 (시·도 우선 적용)

### 안전 게이트

점수가 아무리 높아도 아래에 걸리면 강제로 내려간다.

| 조건 | 상한 |
|---|---|
| 뇌우 | 8점 — 갯벌에서는 사람이 가장 높은 물체다 |
| 짙은 안개(시정 500m 미만) | 18점 — 갯벌 고립 사고의 첫째 원인 |
| 얼어붙는 비 | 20점 |
| 파고 1.5m 이상 | 26점 |
| 젖은 체감 0도 이하 | 26점 |

출조 전 해당 시·도 최신 고시를 확인할 것.

## 자료 파일 (`data/`)

코드를 고치지 않고 이 파일만 바꾸면 반영된다. 정적판은 즉시, 앱스판은 6시간 내.

| 파일 | 내용 |
|---|---|
| `ban-extra.json` | 금어기 보정 |
| `points-extra.json` | 지점 추가·수정 |
| `spots-extra.json` | 세부 포인트 |
| `ferry.json` | 섬 배편 예약처·운항정보 |
| `gear.json` | 준비물 제휴 링크 |
| `videos.json` | 대상물별 잡는 법 영상 |
| `partners.json` · `ads.json` · `monetize.json` | 제휴처·광고·수익 설정 |
| `rigs.json` | 채비 사전 확장 |
| `channels.json` | 제휴 채널 공개 실적 — **코드·채널명·수치만** |

## 제휴 채널 관리

조건과 배분 비율은 [/partner/](https://haerunak.com/partner/) 에 전부 공개해 두었다.
채널은 코드를 받아 [/partner/stats/](https://haerunak.com/partner/stats/) 에서 직접 정산을 확인한다.

운영은 두 층으로 나뉜다.

| | 어디에 | 무엇이 | 누가 본다 |
|---|---|---|---|
| 관리 대장 | 비공개 구글 시트 | 담당자·연락처·계좌·발급 링크·원장 | 운영자만 |
| 공개 실적 | `data/channels.json` | 채널코드·채널명·유입·조회·수익·채널몫 | 코드를 가진 채널 |

개인정보는 저장소에 들어오지 않는다. `channels.json` 에 연락처·계좌를 넣지 말 것.
계좌는 신청 단계에서 받지 않고 첫 정산 직전에만 요청한다.
