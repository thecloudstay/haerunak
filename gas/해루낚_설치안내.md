# 해루낚 — 설치와 사용 안내

물때 해석은 앱이 한다. 사용자는 **어디 가서 뭘 잡을지 결론만** 본다.
정밀 포인트 259곳(도서 165곳 포함)을 매일 자동 채점해 지도에 색으로 뿌리고, 1등을 "오늘의 원픽"으로 올린다.
바다타임 전체 1,571곳은 검색으로 찾아 쓸 수 있고, 처음 고른 순간 조차와 고조간격을 스스로 역산한다.

## 2. 설치 — 10분

1. **script.google.com** 접속 → `새 프로젝트`
2. 프로젝트 이름을 `해루낚` 으로 변경
3. 왼쪽 `파일` 옆 `+` 를 눌러 아래를 **정확히 이 이름으로** 만든다
   - 스크립트 10개: `Code`, `Points`, `Index`, `Tide`, `Model`, `Ban`, `Weather`, `Score`, `Calib`, `Loop`
     (새로 만들면 `.gs` 가 자동으로 붙는다)
   - 에이치티엠엘 3개: `Index`, `Style`, `Script`
     (`+` → `HTML` 선택)
4. 각 파일에 같은 이름의 내용을 통째로 붙여넣는다.
   기본 생성된 `Code.gs` 의 `myFunction` 은 지우고 덮어쓴다.
5. 오른쪽 위 `배포` → `새 배포`
6. 톱니바퀴 → `웹 앱` 선택
   - 설명: `해루낚 1차`
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (혼자만 쓸 거면 `나만`)
7. `배포` → 권한 승인 화면이 뜨면
   `고급` → `해루낚(안전하지 않음)으로 이동` → `허용`
   (본인이 만든 스크립트라 정상이다)
8. 나온 **웹 앱 주소**를 휴대폰에서 열고 홈 화면에 추가한다.
9. **(권장)** 편집기에서 `Loop.gs` 의 `setupLoops` 함수를 한 번 실행한다.
   이후에는 손댈 것이 없다 —
   매시 캐시를 미리 덥히고, 자동 지점을 한 달 주기로 다시 재고,
   바다타임·기상이 죽으면 우회 깃발을 세운 뒤 상태가 바뀔 때만 thecloudstay@gmail.com 으로 메일이 온다.
   금어기 자료가 늙으면 월요일 아침에 갱신 독촉 메일이 온다.

첫 실행은 전국 계산과 외부 조회 때문에 10~20초 걸린다. 이후에는 30분간 캐시가 걸려 즉시 뜬다.

## 3. 화면 사용법

- **위쪽 날짜 칩** — 어제부터 8일 뒤까지. 누르면 그날 기준으로 다시 채점한다.
- **해루질 / 낚시 토글** — 같은 날, 같은 포인트라도 점수와 추천 시간이 완전히 달라진다.
- **오늘의 원픽** — 그날 1등. 결론 한 문장, 진입 시간창, 대상물이 전부다.
- **지도 핀** — 점수와 등급 색. 초록에 가까울수록 좋다. 누르면 상세.
- **아래 시트** — 손잡이를 올리면 전체 순위. `가까운 순` 은 현재 위치 기준(위치 권한 필요).
- **접근 방식 필터** — 전체 / 육지 / 섬 전체 / 차로 가는 섬. 섬은 배편 시간이 목록에 바로 뜬다.
- **찾기(돋보기)** — 두 가지가 들어 있다.
  - **대상 고르기**: 낙지·소라·감성돔처럼 잡을 것을 고르면 그걸 노릴 수 있는 자리만 남기고 순위를 다시 낸다.
    제철이면 초록, 금어기면 빨간 취소선으로 뜨고 눌러도 선택되지 않는다.
  - **지점 이름 검색**: 전국 1,571곳에서 찾는다. 정밀 포인트가 아니면 그 자리에서 자동 보정해 분석한다.
- **상세 화면** — 물때 곡선(야간 음영·추천 구간), 만조·간조, 수중 시야 게이지, 드러나는 갯벌 거리,
  조류·솔루나·달빛 조도, 배편, 점수 분해, 금어기 경고, 비어업인 수칙, 앞으로 7일, 길찾기.

등급은 `S`(88점 이상) `A`(76) `B`(62) `C`(46) `D` 다.

## 4-2. 금어기와 비어업인 제한

`Ban.gs` 가 56개 규정을 담고 있다. 대상물 목록에서 금어기인 것은 **자동으로 빠지고**,
빠진 이유가 상세 화면에 붉은 상자로 뜬다. 시·도 규정이 전국 규정보다 우선한다.

예: 낙지 7월 1일 — 인천은 금어기(6/21~7/20), 충남은 허용. 앱이 지점 행정구역으로 갈라준다.

해루질 화면에는 **비어업인 제한 다섯 가지**가 항상 붙는다.
스쿠버 채취 금지, 허용 도구, 마을어장 어업권, 강원·제주 조례.
실제로 금어기보다 이쪽으로 더 많이 걸린다.

> **⚠ 근거와 한계**
> 국립수산과학원 금어기·금지체장 안내(2024년 5월 기준)를 1차 근거로 했다.
> 국가법령정보센터 원문(2026년 7월 1일 시행판)은 접근하지 못했다.
> 앱은 화면에 기준일자와 재확인 안내를 항상 함께 띄운다. **법적 판단 근거로 쓰면 안 된다.**

## 5. 물때 데이터는 3단으로 가져온다

1. **바다타임** — `m.badatime.com/{지점번호}.html` 월간 물때표를 파싱한다.
   상세 화면은 항상 여기서 가져오고, 지도는 상위 10곳만 병렬로 정밀 보정한다.
   전체 지점은 1,571곳(서해 585 / 남해 793 / 동해 98 / 제주 95)이며 색인을 통째로 담고 있다.
2. **국립해양조사원** — 인증키를 넣으면 2순위로 쓴다(아래 6번).
3. **내장 계산** — 외부가 다 막혀도 항상 동작하는 자체 조석 엔진.
   달 남중 시각 + 지점별 고조간격으로 만조 시각을, 월령과 조석 지연(하루)으로 조차를 낸다.

실측 대조 결과(2026년 8월, 영흥도·여수·학암포)

| 항목 | 정확도 |
|---|---|
| 물때 표기 | 전부 일치 (남해·동해·제주는 서해보다 한 물 앞선 표기까지 반영) |
| 만조·간조 시각 | 평균 오차 10~40분 |
| 조차 | 오차 ±3~11퍼센트 |

지도 색깔은 이 근사로도 충분하고, 사용자가 실제로 보는 상세 시각은 바다타임 실측값이다.

## 7. 포인트 추가·수정

`Points.gs` 배열에 한 줄 넣으면 끝이다.

```javascript
{i:151, n:'영흥도', r:'인천 옹진', s:'W', la:37.2450, lo:126.4800,
 mr:5.81, hi:4.6, f:'mix', sp:['낙지','박하지','소라'], tag:'십리포·장경리'},
```

- `i` — 바다타임 지점번호. `m.badatime.com/151.html` 의 그 숫자
- `s` — `W`서해 `S`남해 `E`동해 `J`제주 (물때 표기와 기본 어종이 갈린다)
- `mr` — 평균 조차(미터). 사리 조차의 0.675배로 넣으면 된다
- `hi` — 달 남중부터 만조까지 걸리는 시간. 서해 북부 4.5, 남해 9~10, 제주 10.5 근처
- `f` — `mud`펄 `sand`모래 `mix`혼합 `rock`갯바위 `none`갯벌없음
- `sp` / `fx` — 그 지점만의 채집물·어종. 생략하면 **해역×바닥질** 기본값 (모래→광어·보리멸, 펄→망둥어·숭어, 암반→감성돔·볼락 식으로 지형이 대상어를 가른다)

새 포인트의 `mr`·`hi` 는 **몰라도 된다.** 번호만 넣고 나머지를 비워두면
`Calib.gs` 가 바다타임 월간표 30일치에서 평균 조차와 고조간격을 역산한다.
고조간격은 12.42시간 주기라 단순 평균이 틀리므로 원형 평균으로 낸다.

도서 지점에는 배편을 넣을 수 있다.

```javascript
isl:1, fr:['성산항', 15, 1]     // 출항지, 소요 분, 차량 선적 가능(1)
isl:1                           // 배편 없이 isl 만 있으면 다리로 연결된 섬
```

## 8. 운영 — 코드 안 고치고 데이터만 고친다

세 가지 "정적" 자료가 이제 저장소의 `data/*.json` 으로 분리됐다.
**깃허브에서 JSON 파일만 수정하면** 사이트판은 즉시, 앱스판은 6시간 안에 반영된다. 재배포 없음.

| 파일 | 무엇을 바꾸나 | 예 |
|---|---|---|
| `data/ban-extra.json` | 금어기 규칙 추가·삭제·기준일 | 개정되면 `add` 에 새 규칙, `remove` 에 옛 이름 |
| `data/spots-extra.json` | 세부 포인트 추가 | `"151": [{"n":"...","t":["낙지"],"d":"...","w":"..."}]` |
| `data/points-extra.json` | 지점 추가·수정 | 같은 번호면 좌표·바닥질만 부분 수정도 됨 |

앱스판은 스크립트 속성 `DATA_BASE` 에 사이트 주소(`https://계정.github.io/haerunak`)를 넣어야 이 파일들을 읽는다.

**금어기는 감시까지 자동이다.** 매주 월요일 루프가 국립수산과학원 안내 페이지의 내용 지문(해시)을 재서,
바뀐 주에만 "페이지가 바뀌었으니 ban-extra.json 을 확인하라"는 메일을 보낸다.
법 내용을 기계가 긁어 적용하지 않는 건 의도다 — 잘못 긁으면 사용자가 법을 어긴다.
**바뀐 사실의 감지는 자동, 적용은 사람 승인**이 이 앱의 원칙이다.

**세부 포인트는 사용자 제보로 자란다.** 상세 화면의 「제보하기」로 들어온 건이
시트 「제보」 탭에 쌓이고, 상태 칸에 `승인` 이라고만 쓰면 1시간 안에 모두에게 공개된다.

## 8-1. 알아둘 것

- 점수는 **판단 보조**다. 최종 안전 판단은 현장에서 직접 한다.
- 야간 해루질은 혼자 들어가지 않는다. 밀물 복귀 시각을 미리 정한다.
- 바다타임은 개인 사이트다. 화면 구조가 바뀌면 파서가 멈출 수 있고,
  그때는 자동으로 내장 계산으로 넘어간다(상세 화면에 `자체 추정` 이라고 뜬다).
- 기상은 Open-Meteo 무료 예보다. 인증키가 필요 없는 대신 연안 격자가 성기다.
  파고 값이 비는 지점은 풍속으로 추정한다.
- 캐시는 물때 6시간, 기상 1시간, 지도 보드 30분이다. 새로고침 버튼을 누르면 다시 계산한다.
